## 模块5：向量存储

### VectorStore — 向量存储实例

```go
type VectorStore struct {
    ID               string            `json:"id"                gorm:"type:varchar(36);primaryKey"`
    UserID           uint64            `json:"user_id"           gorm:"index"`
    Name             string            `json:"name"              gorm:"type:varchar(255);not null"`
    EngineType       string            `json:"engine_type"       gorm:"type:varchar(50);not null"`
    ConnectionConfig ConnectionConfig  `json:"connection_config" gorm:"type:json"`
    IndexConfig      IndexConfig       `json:"index_config"      gorm:"type:json"`
    CreatedAt        time.Time         `json:"created_at"`
    UpdatedAt        time.Time         `json:"updated_at"`
    DeletedAt        gorm.DeletedAt    `json:"deleted_at"        gorm:"index"`
}
```

#### 字段解析

| 字段                 | 类型           | 含义      | 设计意图                                               |
| ------------------ | ------------ | ------- | -------------------------------------------------- |
| `ID`               | varchar(36)  | UUID 主键 | 一个用户可注册多个向量库实例，需要唯一标识                              |
| `UserID`           | uint64       | 所属用户 ID | 用户隔离，不同用户的数据互不可见                                   |
| `Name`             | varchar(255) | 用户自定义名称 | 区分同一用户下的多个向量库（如"生产集群"、"测试集群"）                      |
| `EngineType`       | varchar(50)  | 引擎类型    | 支持 pgvector/Qdrant/Milvus/Weaviate/ES 五种，不同引擎接口差异大 |
| `ConnectionConfig` | JSON         | 连接参数    | 引擎各异，用 JSON 灵活存储，AES 加密敏感字段                        |
| `IndexConfig`      | JSON         | 索引配置    | 维度、度量类型、索引类型等引擎特有参数                                |

**✅ 设计亮点**：ConnectionConfig 把所有引擎的字段放一个 struct 里，只填自己需要的字段，避免了多态继承的复杂性。

```go
type ConnectionConfig struct {

    CollectionName string                   `json:"collection_name"`

    IndexType      string                   `json:"index_type"`
    Extra          map[string]interface{}   `json:"extra"`
}
```

#### 字段解析

| 字段                      | 含义                      | 适用引擎                  |
| ----------------------- | ----------------------- | --------------------- |
| `UseDefaultConnection`  | 复用应用主数据库连接              | PostgreSQL (pgvector) |
| `Host`                  | 连接主机地址                  | PostgreSQL / Qdrant   |
| `Port`                  | 连接端口                    | PostgreSQL / Qdrant   |
| `Username` / `Password` | 认证信息（AES-GCM 加密存储）      | PostgreSQL            |
| `Database`              | 数据库名称                   | PostgreSQL            |
| `SSLMode`               | SSL 连接模式                | PostgreSQL            |
| `UseTLS`                | 是否使用 TLS                | Qdrant                |
| `APIKey`                | API 密钥（AES-GCM 加密存储）    | Qdrant / Weaviate     |
| `GrpcAddress`           | gRPC 地址                 | Weaviate              |
| `Scheme`                | 协议 (http/https)         | Weaviate              |
| `Version`               | 服务端版本号（自动探测）            | Elasticsearch         |
| `CollectionName`        | 集合/索引名称                 | 所有引擎                  |
| `Dimension`             | 向量维度（如 1536、768）        | 所有引擎                  |
| `MetricType`            | 距离度量: cosine / l2 / ip  | 所有引擎                  |
| `IndexType`             | 索引类型: hnsw / ivf / flat | 所有引擎                  |
| `Extra`                 | 引擎特有参数的兜底               | 所有引擎                  |

**✅ 设计亮点**：`Extra` map 给了很好的扩展性，不同引擎的特有参数不需要改 struct。
