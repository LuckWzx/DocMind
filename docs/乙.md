## 模块5：向量存储

### VectorStore — 向量存储实例

```go
// VectorStore 租户注册的向量数据库实例（一个租户可注册多个）
type VectorStore struct {
    ID               string            `json:"id"                gorm:"type:varchar(36);primaryKey"` // UUID主键
    UserID           uint64            `json:"user_id"           gorm:"index"`
    Name             string            `json:"name"              gorm:"type:varchar(255);not null"`  // 用户自定义名称，如"es热集群"
    EngineType       string            `json:"engine_type"       gorm:"type:varchar(50);not null"`   // 引擎类型: postgres / qdrant / milvus / weaviate / elasticsearch
    ConnectionConfig ConnectionConfig  `json:"connection_config" gorm:"type:json"`                  // 连接参数（敏感字段AES加密）
    IndexConfig      IndexConfig       `json:"index_config"      gorm:"type:json"`                  // 索引/集合配置
    CreatedAt        time.Time         `json:"created_at"`
    UpdatedAt        time.Time         `json:"updated_at"`
    DeletedAt        gorm.DeletedAt    `json:"deleted_at"        gorm:"index"`
}

// BeforeCreate GORM钩子——自动生成UUID
func (v *VectorStore) BeforeCreate(tx *gorm.DB) error {
    if v.ID == "" {
        v.ID = uuid.New().String()
    }
    return nil
}
```

| 字段               | 类型         | 含义           | 设计意图                                                     |
| ------------------ | ------------ | -------------- | ------------------------------------------------------------ |
| `ID`               | varchar(36)  | UUID 主键      | 一个用户可注册多个向量库实例，需要唯一标识                   |
| `UserID`           | uint64       | 所属用户 ID    | 用户隔离，不同用户的数据互不可见                             |
| `Name`             | varchar(255) | 用户自定义名称 | 区分同一用户下的多个向量库（如"生产集群"、"测试集群"）       |
| `EngineType`       | varchar(50)  | 引擎类型       | 支持 pgvector/Qdrant/Milvus/Weaviate/ES 五种，不同引擎接口差异大 |
| `ConnectionConfig` | JSON         | 连接参数       | 引擎各异，用 JSON 灵活存储，AES 加密敏感字段                 |
| `IndexConfig`      | JSON         | 索引配置       | 维度、度量类型、索引类型等引擎特有参数                       |

### 搜索请求/响应（乙定义给 VectorStore 接口的）

```go
type SearchFilter struct {
    KnowledgeBaseID string   `json:"knowledge_base_id,omitempty"`
    TagIDs          []string `json:"tag_ids,omitempty"`

}

type SearchParams struct {
    Query      string
    Embedding  []float32
    TopK       int
    Threshold  float64
    Filter     *SearchFilter
    ExcludeIDs []string
}

// SearchResult 统一搜索结果（向量和关键词返回同一格式）
type SearchResult struct {
    ID              string  `json:"id"`               // Chunk ID
    Content         string  `json:"content"`          // Chunk 文本
    Score           float64 `json:"score"`            // 相似度/相关性分数
    KnowledgeID     string  `json:"knowledge_id"`     // 来源知识条目ID
    KnowledgeBaseID string  `json:"knowledge_base_id"` // 来源知识库ID
    ChunkIndex      int     `json:"chunk_index"`      // chunk在文档中的序号
    MatchType       string  `json:"match_type"`       // 匹配类型: vector / keyword
}
```

| 字段         | 含义              | 设计意图                                       |
| ------------ | ----------------- | ---------------------------------------------- |
| `Query`      | 搜索关键词        | 用于关键词检索的 BM25 匹配                     |
| `Embedding`  | 查询向量          | 用于向量检索的语义匹配                         |
| `TopK`       | 返回数量          | 控制返回结果数量                               |
| `Threshold`  | 相似度/相关性阈值 | 过滤低分结果                                   |
| `Filter`     | 过滤条件          | 按 knowledge_base_id、tag_id 等过滤            |
| `ExcludeIDs` | 排除的 chunk ID   | 避免重复召回（如多轮对话中排除已引用的 chunk） |

| 字段              | 含义                 | 设计意图                                             |
| ----------------- | -------------------- | ---------------------------------------------------- |
| `ID`              | Chunk ID             | 唯一标识                                             |
| `Content`         | Chunk 文本           | 检索结果的内容                                       |
| `Score`           | 相似度分数           | 向量检索返回 cosine 相似度，关键词检索返回 BM25 分数 |
| `KnowledgeID`     | 来源知识条目 ID      | 追溯 chunk 的来源                                    |
| `KnowledgeBaseID` | 来源知识库 ID        | 追溯知识条目所属的知识库                             |
| `ChunkIndex`      | chunk 在文档中的序号 | 保持文档中的顺序                                     |
| `MatchType`       | 匹配类型             | 区分 vector / keyword / faq_exact                    |

### 索引策略

```go
// IndexingStrategy 知识库索策略——控制哪些索引管线启用
type IndexingStrategy struct {
    VectorEnabled  bool `json:"vector_enabled"`   // 是否启用语义向量索引
    KeywordEnabled bool `json:"keyword_enabled"`  // 是否启用关键词BM25索引
}

// DefaultIndexingStrategy 默认策略：向量+关键词都开
func DefaultIndexingStrategy() IndexingStrategy {
    return IndexingStrategy{VectorEnabled: true, KeywordEnabled: true}
}
```

| 字段             | 含义                     | 设计意图                       |
| ---------------- | ------------------------ | ------------------------------ |
| `VectorEnabled`  | 是否启用语义向量索引     | 不同知识库可以有不同的索引策略 |
| `KeywordEnabled` | 是否启用关键词 BM25 索引 | FAQ 类型可能只需要向量索引     |

```go
// EventBusInterface 事件总线接口（避免循环依赖）
type EventBusInterface interface {
    On(eventType EventType, handler func(ctx, evt Event) error)
    Emit(ctx context.Context, evt Event) error
}
```
