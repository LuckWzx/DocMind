# 文档质量评审（Document Review）

当用户要求评审某篇文档时，按以下框架执行：

## 评审步骤

1. **结构完整性**：检查文档是否有标题层级、目录、章节划分，内容是否前后连贯
2. **内容准确性**：核对数据、事实、引用是否准确，有无逻辑矛盾或过时信息
3. **语言表达**：检查语法错误、错别字、术语一致性、表达是否清晰
4. **格式规范**：检查排版、编号、图表标注、参考引用格式

## 输出格式

按以下 Markdown 模板输出评审意见：

```markdown
## 📋 文档评审报告

**文档**：《{标题}》

### ✅ 亮点
- {做得好的方面}

### ⚠️ 问题清单
| 严重度 | 维度 | 位置 | 问题描述 |
|--------|------|------|----------|
| 高/中/低 | 结构/内容/语言/格式 | {章节或段落} | {问题描述} |

### 💡 优化建议
1. {可操作的建议}
```

## 注意事项

- 问题要具体到章节/段落，不要泛泛而谈
- 严重度分级：高（影响理解/正确性）、中（影响阅读体验）、低（可改进项）
- 若无明显问题，明确说明"未发现明显问题"而非编造问题
