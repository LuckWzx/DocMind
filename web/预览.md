# 文件预览接口

## 基本信息

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `/api/v1/knowledge/{id}/preview` |
| 认证 | Bearer Token（请求头 `Authorization: Bearer <token>`） |
| 响应类型 | `Blob`（二进制流，`responseType: "blob"`） |

## 请求参数

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | `string` | 是 | 知识文件 ID（knowledge ID） |

### 请求头（自动携带）

| 请求头 | 说明 |
|--------|------|
| `Authorization` | `Bearer <token>`，用户登录后的 JWT |
| `X-Tenant-ID` | 当前激活的租户/空间 ID |
| `X-Request-ID` | 随机生成的请求追踪 ID |
| `Accept-Language` | 用户语言偏好（zh-CN / en-US / ko-KR / ru-RU） |

## 响应说明

### 成功响应

返回文件的**原始二进制内容**（Blob），前端根据文件类型（`fileType`）决定渲染方式：

| 文件类型 | 扩展名 | 前端渲染方式 |
|----------|--------|--------------|
| PDF | `.pdf` | 生成 Blob URL，嵌入 `<iframe>` / `<embed>` 显示 |
| Word 文档 | `.docx` | 前端解析渲染（`renderDocx`） |
| PPT 演示文稿 | `.pptx`, `.ppt` | 通过 `@vue-office/pptx` 组件渲染 |
| 图片 | `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.webp`, `.tiff`, `.svg` | 生成 Blob URL，`<img>` 标签显示 |
| Excel 表格 | `.xlsx`, `.xls`, `.csv` | 前端解析渲染为 HTML 表格（`renderExcel`） |
| Markdown | `.md`, `.markdown` | 前端渲染为 HTML（marked + highlight.js + katex + mermaid） |
| 纯文本 / 代码 | `.txt`, `.json`, `.xml`, `.html`, `.css`, `.js`, `.ts`, `.py`, `.java`, `.go`, `.cpp`, `.c`, `.h`, `.sh`, `.yaml`, `.yml`, `.ini`, `.conf`, `.log`, `.sql`, `.rs`, `.rb`, `.php`, `.swift`, `.kt`, `.scala`, `.r`, `.lua`, `.pl`, `.toml` | 前端语法高亮显示（highlight.js） |
| 音频 | `.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg` | 生成 Blob URL，`<audio>` 标签播放 |
| 其他 | — | 标记为"不支持预览" |

### MIME 类型修正

前端收到 Blob 后，如果响应的 `Content-Type` 与期望不符，会按扩展名修正 MIME 类型再渲染。例如：

| 扩展名 | 期望的 MIME 类型 |
|--------|------------------|
| `.pdf` | `application/pdf` |
| `.docx` | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| `.pptx` | `application/vnd.openxmlformats-officedocument.presentationml.presentation` |
| `.xlsx` | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |
| `.png` | `image/png` |
| `.mp3` | `audio/mpeg` |

### 错误响应

```json
{
  "success": false,
  "code": <错误码>,
  "message": "<错误描述>"
}
```

> **注意**：后端所有错误响应 HTTP 状态码仍为 200，通过 `success: false` 区分。

## 调用示例

```typescript
import { previewKnowledgeFile } from '@/api/knowledge-base/index';

// 请求文件二进制
const blob: Blob = await previewKnowledgeFile(knowledgeId);

// 前端渲染
// PDF / 图片 / 音频：URL.createObjectURL(blob) → <iframe> / <img> / <audio>
// DOCX / Excel / Markdown：读取 blob 内容后前端解析渲染
// PPTX：blob.arrayBuffer() → @vue-office/pptx 组件
```
