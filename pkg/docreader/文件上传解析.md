## GET 列出知识库下的知识

GET /knowledge-bases/{id}/knowledge

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|id|path|string| 是 |知识库 ID|
|--------------|query|-------| 否 |---------------------------------------------------------------------------------------------------|
|`page`|query|integer| 否 |页码（从 1 开始）|
|`page_size`|query|integer| 否 |每页条数|
|`tag_id`|query|string| 否 |按标签 ID 过滤|
|`keyword`|query|string| 否 |按标题/内容关键词过滤|
|`file_type`|query|string| 否 |按单个文件扩展名过滤（如 `pdf`）；特殊值 `manual` / `url` 命中 `type` 列|
|`parse_status`|query|string| 否 |按解析状态过滤：`pending` / `processing` / `completed` / `failed`|
|`source`|query|string| 否 |按来源/渠道过滤：`web` / `api` / `browser_extension` / `feishu` / `notion` / `yuque` / `wechat` 等； 特殊值 `manual` / `url` 命中 `type` 列|
|`start_time`|query|string| 否 |更新时间起点，接受 RFC3339 (`2024-05-01T00:00:00+08:00`) 或 `YYYY-MM-DD HH:MM:SS` / `YYYY-MM-DD`|
|`end_time`|query|string| 否 |更新时间终点，格式同 `start_time`|

## GET 批量获取知识

GET /knowledge/batch

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|-----------|query|--------| 否 |---------------------------------------------------------------------|
|`ids`|query|string[]| 是 |知识 ID，重复 `ids=...` 传多个|
|`kb_id`|query|string| 否 |限定知识库范围；共享知识库场景下用于按 KB 校验权限并解析有效空间|
|`agent_id`|query|string| 否 |共享 Agent ID；按 Agent 所属空间拉取，常用于共享场景刷新后的文件回填|
